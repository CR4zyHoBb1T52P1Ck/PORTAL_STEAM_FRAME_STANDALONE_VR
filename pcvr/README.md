# Portal VR PCVR

Open **Launch-Portal-PCVR-Silent.vbs**. Requires Python3.11+ with Tk, SteamVR and your owned Windows Steam Portal2007.

Select the Portal folder, install/update the mod, apply native rig + accurate eye mirror, start SteamVR, Check setup, then Play.

[Detailed setup and controls](Launcher/docs/GETTING_STARTED.md) · [Features and known gaps](Launcher/RELEASE_NOTES.md).

Commentary HUD and physical red-button touch presses remain unfinished. This is the owner-tested PCVR-10 binary; Frame Heavy Petting is a separate download. No game deadline or automatic log upload.
