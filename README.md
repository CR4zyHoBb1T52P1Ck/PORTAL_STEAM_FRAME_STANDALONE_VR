# The Heavy Petting Update — Contact-55

[Download public beta5](https://github.com/CR4zyHoBb1T52P1Ck/PORTAL_STEAM_FRAME_STANDALONE_VR/releases/tag/v0.1.0-beta.5-contact55) contains the exact last build
I tested on standalone Steam Frame: firmer animated gun grip/contact, improved
lighting/hand visibility, arm calibration and accumulated polish.

**Standalone Frame development is on indefinite hardware hiatus.** My Frame has
stopped charging. After extensive troubleshooting I have contacted Valve support
and am waiting for a fix or possible RMA. There is no confirmed diagnosis or ETA.
I am really sorry to everyone waiting for more, and I hope you still enjoy this
mostly playable version. This is the last standalone update for the foreseeable
future until working hardware and headset acceptance are possible again.

[Release notes](RELEASE_NOTES.md) · [Detailed progress/blockers/hiatus](docs/HEAVY_PETTING_PROGRESS.md)
· [Install/upgrade](docs/GETTING_STARTED.md) · [Validation](docs/RELEASE_VALIDATION.md)

Requires your owned Windows Portal copy. Install.py **and** FrameSetup.py are
required for standalone upgrades; afterward play needs no PC or Wi-Fi.
Contact-56, jiggle skin and climbing experiments are excluded. Portal-heavy
performance remains an issue; no sustained72/90FPS guarantee. Windows PCVR tools
are included but not freshly headset-qualified. Existing credits are preserved.

Earlier releases and the original project description follow as history; the
current release notes supersede their build/testing status.
